# STAT × AI ถอดรหัสข้อมูลด้วยสถิติ ปลดล็อกพลัง AI

คลังข้อมูลและเอกสารประกอบเวิร์กช็อป **STAT × AI** โดย STATBUU สาขาวิชาสถิติ มหาวิทยาลัยบูรพา

ในคลังนี้มีชุดข้อมูลง่าย ๆ สำหรับฝึกอ่านกราฟ ตรวจข้อมูล และใช้ AI (ChatGPT, Claude, Gemini) ช่วยวิเคราะห์ข้อมูล ทุกชุดเล็กพอจะเปิดใน Excel หรืออัปโหลดเข้า AI ได้ทันที

> ⚠️ **ข้อมูลทุกชุดเป็นข้อมูลจำลองเพื่อการสอน** (ยกเว้นชุด Anscombe ซึ่งเป็นข้อมูลคลาสสิกทางสถิติ) ตัวเลขไม่ใช่ค่าตรวจวัดจริง ห้ามนำไปอ้างอิงในงานวิจัยหรือรายงาน ใช้เฉพาะการสอนในคลาสนี้เท่านั้น

## ขั้นตอนการใช้งาน (สำหรับผู้เรียน)

มี 3 วิธี **เวิร์กช็อปนี้ใช้วิธีที่ 1 เป็นหลัก** ไม่ต้องเขียนโค้ด

### วิธีที่ 1: ใช้กับ AI โดยตรง (ง่ายที่สุด ไม่ต้องเขียนโค้ด)

1. เข้าไปที่โฟลเดอร์ `data/` แล้วคลิกชื่อไฟล์ที่ต้องการ เช่น `2_water_level_daily.csv`
2. กดปุ่ม **Download raw file** (ไอคอนลูกศรชี้ลง มุมขวาบน) เพื่อบันทึกไฟล์ลงเครื่อง
3. เปิด ChatGPT, Claude หรือ Gemini แล้วกดปุ่ม 📎 เพื่ออัปโหลดไฟล์
4. เปิดไฟล์ `data/DATA_DICTIONARY.md` แล้วคัดลอกคำอธิบายของไฟล์นั้นไปแปะให้ AI อ่านด้วย AI จะเข้าใจความหมายของคอลัมน์ถูกต้องมากขึ้น
5. เลือกคำสั่งจาก [`prompts/prompts.md`](prompts/prompts.md) ไปถาม หรือเขียนคำถามของตัวเอง
6. **ตรวจคำตอบของ AI เสมอ** โดยดูกราฟเอง และเทียบตัวเลขกับข้อมูลจริง AI ตอบผิดได้

### วิธีที่ 2 (ไม่บังคับ): เปิดใน Google Colab สำหรับคนที่อยากลองเขียน Python

1. เปิดไฟล์ `notebooks/1_start_here.ipynb` ในคลังนี้
2. กดปุ่ม **Open in Colab** ที่อยู่ด้านบนของ notebook (ต้องล็อกอินบัญชี Google)
3. กด **Runtime → Run all** หรือกด ▶ ทีละช่อง
4. ข้อมูลจะถูกดึงจาก GitHub โดยอัตโนมัติด้วยคำสั่ง

   ```python
   import pandas as pd
   url = "https://raw.githubusercontent.com/Pattharaporn-Aon/StatBUU2569-workshop/main/data/2_water_level_daily.csv"
   df = pd.read_csv(url)
   df.head()
   ```

5. เปลี่ยนชื่อไฟล์ท้าย `url` เป็นชุดข้อมูลอื่นได้ตามต้องการ

### วิธีที่ 3: เปิดใน Excel หรือ Google Sheets

1. ดาวน์โหลดไฟล์ .csv ตามวิธีที่ 1 ข้อ 1–2
2. เปิดด้วย Excel หรือลากไฟล์ไปวางใน Google Sheets
3. ไฟล์บันทึกแบบ UTF-8 ภาษาไทยจะแสดงถูกต้อง หากเห็นภาษาไทยเป็นตัวอักษรแปลก ๆ ใน Excel ให้ใช้เมนู **Data → From Text/CSV** แล้วเลือก File Origin เป็น **65001: Unicode (UTF-8)**

## 🧪 กิจกรรมแนะนำ (ใช้ AI ไม่ต้องเขียนโค้ด)

ทุกกิจกรรมทำผ่าน ChatGPT, Claude หรือ Gemini ได้เลย ไม่ต้องเขียน Python ขั้นตอนเหมือนกันทุกข้อ

1. ดาวน์โหลดไฟล์ .csv จากโฟลเดอร์ `data/` (ดูวิธีที่ 1 ด้านบน)
2. อัปโหลดไฟล์เข้า AI แล้วคัดลอก prompt ในกรอบไปวาง
3. **ตรวจคำตอบของ AI** ตามหัวข้อ 🔍 ก่อนเชื่อ
4. ถามต่อด้วย prompt 🤔 เพื่อให้ได้คำอธิบายเชิงสถิติ

> 💡 ทำเป็นคู่ได้ คนหนึ่งพิมพ์ถาม AI อีกคนหนึ่งเป็นคนตรวจคำตอบ

### กิจกรรมที่ 1: ดูกราฟแล้วตอบ
📂 ไฟล์: `1_durian_yield_east.csv`

```
ไฟล์นี้คือผลผลิตทุเรียนเฉลี่ย (กิโลกรัมต่อไร่) ของจังหวัดในภาคตะวันออก
ช่วยทำกราฟแท่งเรียงจากมากไปน้อย ใส่ชื่อกราฟ ชื่อแกน และหน่วยให้ครบ
แล้วบอกว่าจังหวัดไหนผลผลิตต่อไร่สูงที่สุด ตอบเป็นภาษาไทย
```

🔍 ตรวจคำตอบ: เปิดไฟล์ใน Excel หรือ Google Sheets ดูเองว่าค่าสูงสุดตรงกับที่ AI บอกไหม แกน y ของกราฟเริ่มที่ 0 หรือเปล่า

🤔 ถามต่อ:
```
ถ้าเปลี่ยนเป็น pie chart จะเหมาะกว่าหรือแย่กว่ากราฟแท่ง เพราะอะไร
```

### กิจกรรมที่ 2: รูปร่างการกระจาย
📂 ไฟล์: `6_distribution_shapes.csv`

```
ข้อมูลนี้คือคะแนนสอบของนักเรียน 4 ห้อง (4 คอลัมน์)
ช่วยทำฮิสโทแกรมแยก 4 รูป วางเรียงกันแบบ 2x2
แล้วทำตารางเทียบค่าเฉลี่ยกับมัธยฐานของแต่ละห้อง
บอกด้วยว่าแต่ละห้องมีรูปร่างการกระจายแบบไหน
```

🔍 ตรวจคำตอบ: ห้องที่ AI บอกว่า "เบ้ขวา" ค่าเฉลี่ยมากกว่ามัธยฐานจริงไหม ห้องที่เบ้ซ้ายเป็นอย่างไร

🤔 ถามต่อ:
```
ถ้าเป็นครู ควรรายงานคะแนนของแต่ละห้องด้วยค่าเฉลี่ยหรือมัธยฐาน เพราะอะไร
ห้องที่มีสองยอด (bimodal) บอกอะไรเราเกี่ยวกับนักเรียนในห้องนั้น
```

### กิจกรรมที่ 3: ตรวจข้อมูลก่อนใช้ (คนกับ AI ใครหาเจอมากกว่ากัน)
📂 ไฟล์: `3_water_level_daily_dirty.csv`

**รอบที่ 1 หาเอง (10 นาที):** เปิดไฟล์ใน Excel หรือ Google Sheets ใช้ Filter และ Sort หาค่าว่าง แถวซ้ำ และค่าที่ดูผิดปกติ จดไว้

**รอบที่ 2 ให้ AI หา:**
```
ช่วยตรวจคุณภาพข้อมูลไฟล์นี้
- มีค่าว่างกี่ค่า อยู่คอลัมน์ไหน วันที่เท่าไร
- มีแถวซ้ำกี่แถว วันที่เท่าไร
- มีค่าที่ผิดปกติหรือเป็นไปไม่ได้ไหม (เช่น ระดับน้ำติดลบ ฝนมากผิดธรรมชาติ)
สรุปเป็นตาราง และยังไม่ต้องแก้ไขข้อมูล
```

🔍 ตรวจคำตอบ: เทียบรายการของตัวเองกับของ AI จุดไหนที่ AI หาไม่เจอ หรือบอกว่าผิดปกติทั้งที่ไม่ผิด

🤔 ถามต่อ:
```
ค่าผิดปกติแต่ละตัว น่าจะเกิดจากอะไร (พิมพ์ผิด เซ็นเซอร์เสีย หรือเหตุการณ์จริง)
ควรลบ แก้ หรือเก็บไว้ ให้เหตุผลประกอบ
```

### กิจกรรมที่ 4: ไอศกรีมทำให้คนจมน้ำ?
📂 ไฟล์: `4_icecream_drowning.csv`

```
ทำ scatter plot ระหว่างยอดขายไอศกรีม (icecream_sales) กับจำนวนคนจมน้ำ (drowning_cases)
และคำนวณค่าสหสัมพันธ์ (correlation) ระหว่างสองตัวแปรนี้
แปลความหมายว่าสัมพันธ์กันมากน้อยแค่ไหน
```

🔍 ตรวจคำตอบ: ค่าสหสัมพันธ์อยู่ระหว่าง −1 ถึง 1 ไหม จุดบนกราฟเรียงขึ้นตามที่ AI บอกหรือเปล่า

🤔 ถามต่อ:
```
สรุปว่า "กินไอศกรีมทำให้คนจมน้ำ" ได้ไหม เพราะอะไร
ในไฟล์นี้มีตัวแปรไหนที่น่าจะเป็นตัวแปรแทรกซ้อน
```

### กิจกรรมที่ 5: อย่าเชื่อตัวเลขอย่างเดียว
📂 ไฟล์: `5_anscombe.csv`

**รอบที่ 1 ดูตัวเลขอย่างเดียว:**
```
ข้อมูลนี้มี 4 ชุด (คอลัมน์ dataset = I, II, III, IV)
ช่วยคำนวณค่าเฉลี่ยของ x และ y ความแปรปรวน และค่าสหสัมพันธ์ แยกตามชุด ทำเป็นตาราง
ยังไม่ต้องทำกราฟ
```
ทายก่อนว่าทั้ง 4 ชุดหน้าตาเหมือนกันไหม

**รอบที่ 2 ดูกราฟ:**
```
ทำ scatter plot ของทั้ง 4 ชุด วางเรียงแบบ 2x2 ใช้สเกลแกนเดียวกันทุกรูป
แต่ละชุดมีลักษณะต่างกันอย่างไร
```

🤔 ถามต่อ:
```
จากผลนี้ ได้บทเรียนอะไรเกี่ยวกับการวิเคราะห์ข้อมูล
```
