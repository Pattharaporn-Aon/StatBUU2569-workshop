# STAT × AI ถอดรหัสข้อมูลด้วยสถิติ ปลดล็อกพลัง AI

คลังข้อมูลและเอกสารประกอบเวิร์กช็อป **STAT × AI** โดย STATBUU สาขาวิชาสถิติ มหาวิทยาลัยบูรพา

ในคลังนี้มีชุดข้อมูลง่าย ๆ สำหรับฝึกอ่านกราฟ ตรวจข้อมูล และใช้ AI (ChatGPT, Claude, Gemini) ช่วยวิเคราะห์ข้อมูล ทุกชุดเล็กพอจะเปิดใน Excel หรืออัปโหลดเข้า AI ได้ทันที

> ⚠️ **ข้อมูลทุกชุดเป็นข้อมูลจำลองเพื่อการสอน** (ยกเว้นชุด Anscombe ซึ่งเป็นข้อมูลคลาสสิกทางสถิติ) ตัวเลขไม่ใช่ค่าตรวจวัดจริง ห้ามนำไปอ้างอิงในงานวิจัยหรือรายงาน ใช้เฉพาะการสอนในคลาสนี้เท่านั้น

## 🚀 ขั้นตอนการใช้งาน (สำหรับผู้เรียน)

มี 3 วิธี เลือกวิธีที่สะดวกที่สุด

### วิธีที่ 1: ใช้กับ AI โดยตรง (ง่ายที่สุด ไม่ต้องเขียนโค้ด)

1. เข้าไปที่โฟลเดอร์ `data/` แล้วคลิกชื่อไฟล์ที่ต้องการ เช่น `02_water_level_daily.csv`
2. กดปุ่ม **Download raw file** (ไอคอนลูกศรชี้ลง มุมขวาบน) เพื่อบันทึกไฟล์ลงเครื่อง
3. เปิด ChatGPT, Claude หรือ Gemini แล้วกดปุ่ม 📎 เพื่ออัปโหลดไฟล์
4. เปิดไฟล์ `data/DATA_DICTIONARY.md` แล้วคัดลอกคำอธิบายของไฟล์นั้นไปแปะให้ AI อ่านด้วย AI จะเข้าใจความหมายของคอลัมน์ถูกต้องมากขึ้น
5. เลือกคำสั่งจาก [`prompts/prompts.md`](prompts/prompts.md) ไปถาม หรือเขียนคำถามของตัวเอง
6. **ตรวจคำตอบของ AI เสมอ** โดยดูกราฟเอง และเทียบตัวเลขกับข้อมูลจริง AI ตอบผิดได้

### วิธีที่ 2: เปิดใน Google Colab (เขียน Python บนเว็บ ไม่ต้องติดตั้งอะไร)

1. เปิดไฟล์ `notebooks/01_start_here.ipynb` ในคลังนี้
2. กดปุ่ม **Open in Colab** ที่อยู่ด้านบนของ notebook (ต้องล็อกอินบัญชี Google)
3. กด **Runtime → Run all** หรือกด ▶ ทีละช่อง
4. ข้อมูลจะถูกดึงจาก GitHub โดยอัตโนมัติด้วยคำสั่ง

   ```python
   import pandas as pd
   url = "https://raw.githubusercontent.com/Pattharaporn-Aon/StatBUU2569-workshop/main/data/02_water_level_daily.csv"
   df = pd.read_csv(url)
   df.head()
   ```

5. เปลี่ยนชื่อไฟล์ท้าย `url` เป็นชุดข้อมูลอื่นได้ตามต้องการ

### วิธีที่ 3: เปิดใน Excel หรือ Google Sheets

1. ดาวน์โหลดไฟล์ .csv ตามวิธีที่ 1 ข้อ 1–2
2. เปิดด้วย Excel หรือลากไฟล์ไปวางใน Google Sheets
3. ไฟล์บันทึกแบบ UTF-8 ภาษาไทยจะแสดงถูกต้อง หากเห็นภาษาไทยเป็นตัวอักษรแปลก ๆ ใน Excel ให้ใช้เมนู **Data → From Text/CSV** แล้วเลือก File Origin เป็น **65001: Unicode (UTF-8)**

## 🧪 กิจกรรมแนะนำ

1. **ดูกราฟแล้วตอบ:** ใช้ `1_durian_yield_east.csv` ทำกราฟแท่ง แล้วตอบว่าจังหวัดไหนผลผลิตทุเรียนต่อไร่สูงที่สุด และทำไมกราฟแท่งจึงเหมาะกว่า pie chart
2. **รูปร่างการกระจาย:** ใช้ `6_distribution_shapes.csv` ทำฮิสโทแกรมทั้ง 4 คอลัมน์ แล้วเทียบค่าเฉลี่ยกับมัธยฐานของแต่ละคอลัมน์
3. **จัดการข้อมูล:** ใช้ `3_water_level_daily_dirty.csv` หาให้ได้ว่ามีค่าว่างกี่ค่า มีแถวซ้ำกี่แถว และมีค่าผิดปกติตรงไหน แล้วลองให้ AI หาเหมือนกัน AI หาครบไหม
4. **ไอศกรีมทำให้คนจมน้ำ?:** ใช้ `4_icecream_drowning.csv` คำนวณสหสัมพันธ์ แล้วอธิบายว่าทำไมสรุปว่าเป็นเหตุและผลไม่ได้
5. **อย่าเชื่อตัวเลขอย่างเดียว:** ใช้ `5_anscombe.csv` คำนวณค่าเฉลี่ยและสหสัมพันธ์ของทั้ง 4 ชุด แล้วพล็อตกราฟเทียบกัน

## 📌 ข้อควรระวังเมื่อใช้ AI วิเคราะห์ข้อมูล

- AI อาจคำนวณผิด หรือ "เดา" ตัวเลขที่ไม่มีในข้อมูล ให้ขอให้ AI แสดงโค้ดหรือวิธีคิดทุกครั้ง
- อย่าอัปโหลดข้อมูลส่วนบุคคล (ชื่อ เลขบัตร คะแนนของเพื่อน) เข้า AI
- AI ช่วยคิดได้ แต่คนที่ต้องตัดสินใจและรับผิดชอบผลการวิเคราะห์คือเรา
