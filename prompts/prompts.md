# ตัวอย่างคำสั่ง (Prompt) สำหรับใช้ AI วิเคราะห์ข้อมูล

วิธีใช้: อัปโหลดไฟล์ .csv เข้า ChatGPT, Claude หรือ Gemini แปะคำอธิบายจาก `data/DATA_DICTIONARY.md` แล้วคัดลอกคำสั่งด้านล่างไปใช้

> 💡 **เคล็ดลับ:** prompt ที่ดีควรบอก (1) ข้อมูลคืออะไร (2) อยากได้อะไร (3) อยากให้ตอบในรูปแบบไหน

---

## 1. เริ่มต้นทำความรู้จักข้อมูล

```
ไฟล์นี้คือข้อมูลระดับน้ำแม่น้ำและปริมาณฝนรายวันตลอดปี 2025
ช่วยสรุปให้หน่อยว่ามีกี่แถว กี่คอลัมน์ แต่ละคอลัมน์เป็นข้อมูลประเภทไหน
และสรุปค่าสถิติพื้นฐาน (ค่าเฉลี่ย มัธยฐาน ค่าต่ำสุด ค่าสูงสุด) ของคอลัมน์ water_level_m
ตอบเป็นภาษาไทย และแสดงโค้ด Python ที่ใช้คำนวณด้วย
```

## 2. ทำกราฟ

```
ช่วยทำฮิสโทแกรมของคอลัมน์ water_level_m และ boxplot ของ water_level_m แยกตามเดือน
แล้วอธิบายว่า (1) การกระจายเบ้ไปทางไหน (2) เดือนไหนน้ำขึ้นสูงที่สุด เสี่ยงน้ำท่วม
(3) ระดับน้ำสัมพันธ์กับปริมาณฝน (rain_mm) ไหม
ใส่ชื่อแกนและหน่วยให้ครบ
```

## 3. ตรวจข้อมูลก่อนใช้ (ใช้กับ 03_water_level_daily_dirty.csv)

```
ช่วยตรวจคุณภาพข้อมูลไฟล์นี้ให้หน่อย
- มีค่าว่างกี่ค่า อยู่คอลัมน์ไหน
- มีแถวซ้ำกี่แถว
- มีค่าที่ผิดปกติหรือเป็นไปไม่ได้ไหม (เช่น ระดับน้ำติดลบ ฝนมากผิดธรรมชาติ) อยู่วันที่เท่าไร
สรุปเป็นตาราง และยังไม่ต้องแก้ไขข้อมูล
```

ต่อด้วย:

```
ค่าผิดปกติแต่ละตัวที่เจอ น่าจะเกิดจากอะไร (พิมพ์ผิด เซ็นเซอร์เสีย หรือเหตุการณ์จริง)
และควรจัดการอย่างไร ให้เหตุผลประกอบ
```

## 4. สหสัมพันธ์กับเหตุและผล (ใช้กับ 04_icecream_drowning.csv)

```
คำนวณสหสัมพันธ์ระหว่าง icecream_sales กับ drowning_cases
แล้วตอบว่า "การกินไอศกรีมทำให้คนจมน้ำ" สรุปแบบนี้ได้ไหม เพราะอะไร
มีตัวแปรไหนในข้อมูลที่น่าจะเป็นตัวแปรแทรกซ้อน
```

## 5. ทำไมต้องพล็อตกราฟ (ใช้กับ 05_anscombe.csv)

```
คำนวณค่าเฉลี่ยของ x และ y ความแปรปรวน และสหสัมพันธ์ แยกตาม dataset ทั้ง 4 ชุด
จากนั้นพล็อต scatter plot ของทั้ง 4 ชุดเทียบกันแบบ 2x2
แล้วสรุปว่าได้บทเรียนอะไร
```

## 6. รูปร่างการกระจาย (ใช้กับ 06_distribution_shapes.csv)

```
ข้อมูลนี้คือคะแนนสอบของนักเรียน 4 ห้อง (4 คอลัมน์)
ช่วยทำฮิสโทแกรมทั้ง 4 คอลัมน์ เทียบค่าเฉลี่ยกับมัธยฐานของแต่ละห้อง
และบอกว่าแต่ละห้องมีรูปร่างการกระจายแบบไหน ถ้าเป็นครู จะเลือกรายงานค่าเฉลี่ยหรือมัธยฐาน เพราะอะไร
```

## 7. เปรียบเทียบรายภาค (ใช้กับ 07_rainfall_provinces.csv)

```
ช่วยหาค่าเฉลี่ยปริมาณฝนรายปีแยกตามภาค เรียงจากมากไปน้อย
และบอก 5 จังหวัดที่ฝนตกมากที่สุด ทำเป็นกราฟแท่งด้วย
```
